# MafSubAgent

A friendly chatbot assistant built using Azure OpenAI and Microsoft Agents framework.

## Description

This agent acts as a career advisor: it helps users explore career paths, identify suitable roles, improve their CVs, prepare for interviews, and develop professional skills. It provides practical, clear, and personalized guidance based on the user's goals, skills, and experience.
